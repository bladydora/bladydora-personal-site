开发项目

  • LearningMap

    Next.js · Supabase · Gemini

    终身学习顾问。和 AI 自然聊天，自动整理成按领域与优先级组织的个人学习档案，数据存在你自己的 Supabase 里。

    Streamlit · Supabase

    给对话装上记忆。重要性评分、自动分类、导入外部对话记录、超期归档，还有一层会自己浮现的待办认知层。

  • WeChat Courier

    macOS · CLI · MCP

    本地 macOS 边车程序，用 UI 自动化驱动已登录的微信桌面端发消息和文件。不实现协议机器人，只操作界面；同时提供 CLI、队列模式和 MCP 服务。

    ASR · LLM

    给会议和视频课程做的实时翻译。
